# Monitoring API

## Endpoints

- `GET /api/v1/monitoring/metrics/` — Get monitoring metrics
- `POST /api/v1/monitoring/metrics/reset/` — Reset monitoring metrics

## Notes

- Use for operational observability. Combine with health endpoints from `api-health-info.md`.
